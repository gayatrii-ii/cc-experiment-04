## ✨ Features

- **Responsive Design:** Mobile-first layout optimized for desktops, tablets, and mobile devices.
- **Dark / Light Theme Toggle:** Seamless switching with local storage persistence and system preference detection.
- **Live Clock & Date:** Real-time synchronized clock displaying current hours, minutes, and seconds.
- **Interactive Counter:** Dynamic state management demonstrating basic DOM manipulation and event listeners.
- **Random Hex Color Generator:** Instant palette generator with 1-click clipboard copying.
- **Interactive Greeting Form:** Dynamic user input handling with custom toast notifications.

## 🚀 How to Enable GitHub Pages (if not already active)

1. Open this repository on GitHub: [cc-experiment-04](https://github.com/gayatrii-ii/cc-experiment-04).
2. Click on **Settings** tab at the top.
3. In the left sidebar, navigate to **Pages** under the *Code and automation* section.
4. Under **Build and deployment**:
   - **Source**: Select `Deploy from a branch`.
   - **Branch**: Choose `main` (or `gh-pages`) and folder `/ (root)`.
   - Click **Save**.
5. Wait 1–2 minutes for GitHub Actions to complete the deployment. Your site will be live at:
   `https://gayatrii-ii.github.io/cc-experiment-04/`
