Learn the concepts, applications, and working principles of cloud computing through this practical.

Explore Experiment
🎯

Aim

To study and demonstrate a fundamental concept of cloud computing using a simple interactive web application.

Demonstrate provisioning, hosting, and simulated scaling of a website on cloud infrastructure (GitHub Pages).

📘

Theory

Cloud computing provides computing services such as servers, storage, databases, networking, and software over the internet.

☁️

Cloud Services

Access computing resources over the internet.

⚙️

Virtualization

Use virtual resources to improve flexibility.

📈

Scalability

Adjust resources according to demand.

💻

Software Requirements

  • Computer or Laptop
  • Internet Connection
  • Google Chrome or Microsoft Edge
  • HTML, CSS and JavaScript
  • GitHub Account
  • GitHub Pages for deployment
📑

Procedure

  1. Create an HTML file for the webpage.
  2. Design the page using CSS.
  3. Add interactive functionality using JavaScript.
  4. Run the website in a web browser.
  5. Test the demonstration and observe the output.
🚀

Interactive Demonstration

Click the button to simulate a cloud service starting and stopping.

Result

The experiment webpage was created using HTML, CSS, and JavaScript. The interactive demonstration illustrates the basic working of a simulated cloud service.

This is a browser-based simulation; it does not start or stop a real cloud server.
