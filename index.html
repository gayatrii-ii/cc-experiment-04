Core Fundamentals

What is Cloud Computing?

According to the National Institute of Standards and Technology (NIST), cloud computing is a model for enabling ubiquitous, convenient, on-demand network access to a shared pool of configurable computing resources.

The Paradigm Shift

Traditional IT vs. Cloud Computing

In traditional on-premises infrastructure, organizations had to purchase physical servers, build cooling facilities, and hire dedicated maintenance teams (Capital Expenditure - CapEx). Cloud computing replaces this with an Operational Expenditure (OpEx) utility model.

  • Pay-as-you-go: Pay only for the compute cycles and storage you actually consume.
  • Zero Upfront Hardware: Spin up 100 enterprise servers in seconds with zero hardware procurement.
  • Global Reach: Deploy applications in multiple continents within minutes via edge networks.
  • Fault Tolerance & High Availability: Redundant multi-region availability zones protect against downtime.
Key Drivers

Why Do Modern Enterprises Use the Cloud?

🚀
Agility & Speed:

Reduces provisioning lead time from months to seconds, allowing rapid experimentation.

🛡️
Automated Disaster Recovery:

Continuous geo-replicated backups ensure business continuity during catastrophic failures.

🔄
Elastic Scaling:

Automatically scales compute instances up during traffic spikes and down during quiet hours.

Service Hierarchy

The SPI Cloud Service Models

Cloud computing services are categorized into three core abstraction layers: IaaS, PaaS, and SaaS.

IaaS

Infrastructure as a Service

Provides fundamental raw computing resources such as virtual machines, raw storage, firewalls, and virtual networks.

Key Characteristics:
  • Maximum architectural control
  • User manages OS, runtimes & apps
  • Highly scalable virtualization
Examples: AWS EC2 / S3 Google Compute Engine Azure VMs
PaaS

Platform as a Service

Provides a managed cloud environment for developers to build, test, run, and scale applications without managing OS or hardware.

Key Characteristics:
  • Automated patching, scaling & OS
  • Built-in deployment pipelines
  • Developer-centric productivity
Examples: AWS Elastic Beanstalk Google App Engine Heroku
SaaS

Software as a Service

Delivers complete end-user software applications hosted in the cloud, accessed through a web browser or mobile client.

Key Characteristics:
  • Zero installation or infrastructure setup
  • Accessible on any device anywhere
  • Subscription or freemium pricing
Examples: Google Workspace Microsoft 365 Salesforce

Topologies

Cloud Deployment Models

Deployment models define who owns, manages, and accesses the cloud infrastructure.

🌍

Public Cloud

Resources (servers, storage) are owned and operated by a third-party cloud provider and shared across multiple tenants over the public internet.

✓ Lowest upfront costs ✓ Near-infinite scalability ✗ Shared infrastructure concerns
🏢

Private Cloud

Cloud infrastructure provisioned for exclusive use by a single organization comprising multiple consumers (business units).

✓ Maximum security & compliance ✓ Custom hardware configurations ✗ Higher CapEx & maintenance
🔀

Hybrid Cloud

Combines private and public clouds, bound together by standardized technology allowing data and application portability ("cloud bursting").

✓ Optimal balance of cost & control ✓ Sensitive data stays on-prem ✗ Complex integration & networking
🤝

Community Cloud

Infrastructure shared exclusively by several organizations with shared concerns (e.g., regulatory compliance, research consortiums).

✓ Shared financial & resource burden ✓ Tailored industry compliance ✗ Limited storage & bandwidth caps
